FORM PWA — INSTALL

1. Create a public GitHub repository (e.g. form-workout).
2. Upload the CONTENTS of this folder to the repository root (index.html, manifest.webmanifest, sw.js, icons folder).
3. Go to repository Settings > Pages > Build and deployment. Select Deploy from a branch, main, /(root), Save.
4. Wait for the GitHub Pages link (typically https://YOURNAME.github.io/form-workout/).
5. On Android open that HTTPS link in Chrome, tap the three-dot menu > Add to Home screen > Install.
6. Open the new FORM icon. Once loaded, it works offline.

Workouts are saved in browser local storage, specific to this website and browser. Export backups periodically. If you used the original HTML app, export its JSON backup and import it into the PWA. Do not clear site data without a backup.
